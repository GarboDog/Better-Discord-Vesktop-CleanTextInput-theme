# Better-Discord-Vesktop-CleanTextInput-theme
Better Discord/Vesktop Theme aimed towards removing annoying things and nitro begging

Most recent of [Clean Text Input Version 1.5](https://github.com/GarboDog/Better-Discord-Vesktop-CleanTextInput-theme/blob/main/CleanTextInput.theme%20v1.5.css)

Required: Better Discord or Vesktop, the most up to date .css file

how to: Themes > Open themes folder > put the .css file in there, refresh themes and enable.

Line 58 where .appMount__51fd7 is, thats what pushes and resizes discord for the top bar to be hidden. If you want to disable that, just comment or delete that section. 🐶👍
