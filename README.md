# Better-Discord-Vesktop-CleanTextInput-theme
Better Discord/Vesktop Theme aimed towards removing annoying things and nitro begging

![Removal of the emoji, gif, gift nitro buttons in the chat text bar](https://i.imgur.com/ZgWw4l3.png)

Most recent of [Clean Text Input Version 1.7](https://github.com/GarboDog/Better-Discord-Vesktop-CleanTextInput-theme/blob/main/CleanTextInput.theme%20v1.7.css)

Required: Better Discord or Vesktop, the most up to date .css file

How to: Themes > Open themes folder > put the .css file in there, refresh themes and enable.

Optionally disable Discord's default Top-Bar, Remove the divider between beg buttons to DMS, and hide the Pin icons 🐶👍

![Removal of Nitro, Quest and Shop buttons](https://i.imgur.com/amuCH5h.png)
![Romoval of the top bar when using native window frame](https://i.imgur.com/R6aptO2.png)
